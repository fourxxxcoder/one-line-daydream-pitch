One-line pitch for make.fun's **A Day of One-Line Pitches** bounty
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

## The pitch (237 characters, one sentence)

> That app idea you keep bringing up at lunch, tell it in plain words to an AI agent on make.fun and it builds a working first version you can tap, tweak, and show your friends, free to try, and if it flops, you have only spent a daydream.

## Run it

```sh
python3 main.py
```

The program writes the sentence above, exactly as-is, to
`/output/entry.txt` (UTF-8, no trailing newline). It uses only the
Python 3.13 standard library and is deterministic: every run produces
the identical file.

## Why this sentence

- **It talks to the friend, not about the product:** it opens on the
  friend's own idea ("that app idea you keep bringing up at lunch").
- **Concrete reason to say yes now:** describe the idea in plain
  words, get a working first version to tap, tweak, and show friends.
- **Low risk:** free to try, and the worst case is framed as only
  having "spent a daydream".
- **Truthful:** it promises a working first version, not a finished
  business, and no coding skill from the friend.
- **Warmth and craft:** a question hook, three concrete verbs, and a
  fresh closing image instead of a slogan.
